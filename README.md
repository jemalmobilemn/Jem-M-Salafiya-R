# Jem Salafiya AI

ይህ ኘሮጀክት በ **jem-m-salafiya-r.vercel.app** ላይ የሚሰራ የ AI ቻት አፕሊኬሽን ነው።

## ፋይሎች
- `index.html`: ዋናው የድረ-ገጽ መዋቅር
- `style.css`: የዲዛይን እና የ Dark/Light mode ገጽታዎች
- `app.js`: የቻት እና የተጠቃሚ መስተጋብር ኮድ
- `manifest.json`: የ PWA አፕሊኬሽን መረጃ
- `sw.js`: ከመስመር ውጭ (Offline) ለመጠቀም የሚያስችል Service Worker
- `api/`: የ backend/API ማስተናገጃ ፎልደር
